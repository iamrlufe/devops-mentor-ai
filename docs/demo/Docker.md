# Docker

Docker упаковывает приложение вместе с его зависимостями в образ.

## Образ и контейнер

Образ описывается в `Dockerfile` и собирается командой:

```bash
docker build -t my-app .
```

Контейнер — это запущенный экземпляр образа:

```bash
docker run -d --name my-app -p 8000:8000 my-app
```

## Полезные команды

- `docker ps` — список запущенных контейнеров;
- `docker logs -f my-app` — чтение логов в реальном времени;
- `docker exec -it my-app sh` — оболочка внутри контейнера;
- `docker compose up -d` — запуск всех сервисов из `docker-compose.yml`.

## Практика

Слои образа кэшируются, поэтому зависимости копируют и устанавливают до
копирования исходного кода — тогда изменение кода не запускает переустановку
зависимостей заново.
